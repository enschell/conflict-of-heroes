# Awakening the Bear (3rd ed.) — Rules Index  
*Reference index for the v3 rules. The project handoff is the repo-root `CLAUDE.md`.*

*Conflict of Heroes: Awakening the Bear* (3rd edition) rulebook, split into one file per numbered chapter under `rules/`. The root `CLAUDE.md` routes here; read the relevant `rules/NN-*.md` on demand.

## How to use these rules

**IMPORTANT — routing rule:** When answering a question about this game, first identify which numbered chapter(s) below cover it, then read the matching `rules/NN-*.md` file(s) **before** answering. Do not answer rules questions from this index alone — it only says where each rule lives. Read more than one file when a question spans chapters (e.g. an attack through smoke onto a vehicle touches 6, 14, and 15).

Notes: (1) Section numbers are stable references — rules cross-cite each other as `(N.M)`; follow those into the relevant file. (2) Text was auto-extracted from a diagram-heavy layout, so diagrams, red example boxes, and blue designer notes are **not** in the text — the printed page numbers in each file point back to the source PDF when a figure matters. (3) The rulebook teaches progressively: chapters 1–9 are core; 10+ add mechanics introduced over later missions.
